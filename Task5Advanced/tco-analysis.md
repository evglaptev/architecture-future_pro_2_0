## Допущения

- Курсовая разница не учитывается, все суммы в млн ₽.
- В текущем ландшафте используется on-prem hardware, лицензии SQL Server/Power BI, ручная поддержка.
- В целевой архитектуре инфраструктура арендуется в облаке (Yandex Cloud), расчёт учитывает autoscaling.

## Экономический эффект

- Суммарный TCO за 3 года: **текущий** 570 млн ₽ vs **целевой** 418 млн ₽ (экономия 152 млн ₽).
- Payback наступает между 18 и 24 месяцем, когда отключается большая часть SQL Server лицензий и on-prem инфраструктуры.
- Дополнительный немонетарный эффект: ускорение вывода продуктов (1–2 недели вместо 1–2 месяцев), снижение штрафов за несоблюдение SLA данных.
